# Ponto de Recomeço
Site acadêmico da ONG fictícia Ponto de Recomeço.

## Construção do projeto
HTML5, CSS3 e JavaScript.

## Acessibilidade e testes
Foram revisados contraste, foco visível, navegação por teclado, textos alternativos, estrutura semântica e mensagens de formulário.

## Imagens
As fotografias principais possuem versão WebP e carregamento lazy.

## Execução e publicação
Para preparar a versão de produção: `npm install` e `npm run build`. A pasta `dist` é usada na publicação.
## Organização do versionamento

Usei a branch `main` para a versão principal do projeto e a `develop` para organizar as alterações antes de levá-las para a versão final. Para as melhorias de acessibilidade, também usei a branch `feature/acessibilidade`.

Os commits foram identificados de acordo com o tipo de alteração, usando `feat` para funcionalidades e melhorias, `fix` para correções e `docs` para alterações na documentação.
