# Ponto de Recomeço
Site acadêmico da ONG fictícia Ponto de Recomeço.

## Construção do projeto
HTML5, CSS3 e JavaScript.

## Acessibilidade e testes
Foram revisados contraste, foco visível, navegação por teclado, textos alternativos, estrutura semântica e mensagens de formulário.

## Imagens
As fotografias principais possuem versão WebP e carregamento lazy.

## Execução e publicação
Para preparar a versão de produção: `npm install` e `npm run build`. A pasta `dist` é usada na publicação.
